# Job Application Tracker

## Project Overview
Job Application Tracker is a console-based application developed using Python to manage job application details in one place. It helps users track the companies they have applied to and monitor their application status.

## Features
- **Add Application:** Add company name, job role, location, application date, and status.
- **View Applications:** Display all stored job applications.
- **Update Application:** Modify job role, location, application date, or status.
- **Delete Application:** Delete an application by company name or status.
- **Search Application:** Search applications using their stored details.
- **Dashboard:** View the total number of applications and counts by status.
- **History:** View previously deleted or cleared application records.
- **Duplicate Prevention:** Prevent adding applications with an existing company name.

## Technologies Used
- Python
- Dictionaries and Lists
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run
1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python job_application_tracker.py
```

## Application Status
The dashboard tracks these statuses:
- Applied
- Interview
- Selected
- Rejected
